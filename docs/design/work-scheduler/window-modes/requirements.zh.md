# 工作调度窗口模式需求

[English](requirements.md) | 中文

## 原始需求

> 工作调度这个弹窗可以适当的缩放，可以有个放大全屏按钮。

“工作调度”弹窗应以合适的窗口尺寸打开，支持缩放，并提供放大至应用视口的控件。

> 新增任务，会话有可能是新增。

新建任务时，关联对象也必须允许是新建对话，而不只限于已有 Session。

> 部分工作进度我希望你参考 dashi-taskboard 这个项目实现。

进行中的任务卡应参考 dashi-taskboard 已采用的分段 Todo 展示，从关联 Session 投影有用的工作进度。

## 需求拆解

### 功能需求

| ID | 需求 |
|---|---|
| FR-01 | 在桌面视口上打开“工作调度”时，默认显示居中窗口，不立即覆盖完整应用视口。 |
| FR-02 | 窗口默认尺寸约为 `92vw` × `86vh`，不超出视口，并支持指针缩放，但不得小于布局可用的最小尺寸。 |
| FR-03 | 标题栏控件在窗口模式和应用全屏模式之间切换。从全屏还原时，窗口恢复放大前的位置和尺寸。 |
| FR-04 | 现有关闭按钮和 `Escape` 会关闭整个“工作调度”弹窗。打开关联会话时，选中该会话后也会关闭整个弹窗。 |
| FR-05 | 关闭后重新打开“工作调度”时，恢复默认窗口尺寸；窗口尺寸和全屏状态均不持久化。 |
| FR-06 | 小视口使用现有响应式内容布局，并以应用全屏弹窗显示，不展示不适用的缩放或放大控件。 |
| FR-07 | 帮助面板在窗口和全屏模式下均限制在“工作调度”窗口内。 |
| FR-08 | 标题栏中的单个`新建`菜单提供`新建任务`与`新建线程`；两种编辑器互斥显示，且不再常驻任何创建表单。 |
| FR-09 | 任务的 Session 选择器会把`新建并打开对话`和`不关联对话`固定显示在当前 Workspace 的已有 Session 之前；搜索只过滤这些已有 Session。 |
| FR-10 | 选择`新建并打开对话`后提交，会在当前 Workspace 创建 Session，把任务描述写入尚未发送的输入草稿，添加关联该 Session 的任务，关闭“工作调度”，并打开新 Session。 |
| FR-11 | 如果新建 Session 失败，则不添加任务；任务草稿、所选位置和编辑器会继续保留，并显示可重试错误。 |
| FR-12 | 进行中的任务关联可用 Session 且 Todo 投影非空时，显示分段 Todo 进度、已完成项数／总项数和当前 `in_progress` 项。其他任务状态以及缺失或为空的投影不显示进度区。 |

### 非功能需求

| ID | 需求 |
|---|---|
| NFR-01 | 标题栏控件、表单、泳道、任务卡、检查器和可见文本在支持的视口与窗口尺寸下不得重叠。 |
| NFR-02 | 放大控件具有随模式在 `全屏` 和 `还原` 之间变化的无障碍名称；切换模式时，键盘焦点保持在该控件上。 |
| NFR-03 | 缩放和模式变化只影响展示，不得修改或保存调度文档。 |
| NFR-04 | 设计继续使用现有主题 token 和图标原语，不引入独立的视觉语言。 |
| NFR-05 | 打开任一创建编辑器时，第一个输入控件会获得焦点；按 `Escape` 会依次关闭 Session 选择器、创建菜单、当前编辑器和完整弹窗。 |
| NFR-06 | Session 创建待处理期间，如果用户取消、切换编辑器、更换 Workspace 或关闭弹窗，则该次提交失效；延迟返回的结果不得添加任务或重新打开对话。 |
| NFR-07 | Todo 进度提供 progressbar 语义及稳定的已完成项数和总项数；每份投影为每个 Todo 渲染一个等宽分段，且不改变调度器状态。 |

### 约束

- 全屏指填满 dsh 应用视口；该功能不调用浏览器 Fullscreen API，也不隐藏浏览器界面。
- 改动保持在现有 `shell.overlay` 贡献以及 Client 的 Session 与 conversation 服务内，不新增 Host API、调度存储字段、Session 事件或模型可见输入。
- 新建 Session 操作要求存在当前 Workspace。只有 Session 创建和草稿写入成功后才添加任务，且预填草稿不会自动发送。
- 进度只读投影 `SessionSummary.projectionValues.todos`；调度器不会追加 `todo/write` 事件，也不会把 Todo 数据持久化到调度文档。
- 点击遮罩层不关闭弹窗，避免意外丢失用户当前的视觉上下文。
- 通过拖动标题栏移动窗口，以及跨打开或浏览器重载持久化窗口几何信息，不属于本次范围。

### 验收标准

| ID | 验收标准 |
|---|---|
| AC-01 | 在 `1564x996` 视口下，“工作调度”打开后窗口周围存在可见留白，四泳道看板仍可用，必要时看板区域可水平滚动。 |
| AC-02 | 拖动缩放控件会改变窗口尺寸，且不会让控件或检查器缩小到受支持的最小布局以下。 |
| AC-03 | 触发 `全屏` 会填满应用视口；触发 `还原` 会恢复之前的窗口位置和尺寸。 |
| AC-04 | 在缩放或全屏切换后关闭弹窗，再次打开时会恢复默认窗口尺寸。 |
| AC-05 | 点击可用的会话关联会选中该会话，并移除“工作调度”弹窗，无需再次关闭。 |
| AC-06 | 在窄视口上，“工作调度”填满应用视口，且不显示放大控件和缩放控件。 |
| AC-07 | 组件测试覆盖模式转换和关闭行为；真实 Web 测试覆盖用户可见的导航和弹窗结果。 |
| AC-08 | 标题栏创建菜单会打开所选的任务或线程编辑器；切换编辑器会丢弃前一个编辑器的草稿，关闭编辑器则恢复紧凑的调度器布局。 |
| AC-09 | 选择`新建并打开对话`并提交任务后，会显示一个新对话，其尚未发送的输入区中包含任务描述，同时调度任务保存该 Session 的 ID。 |
| AC-10 | Session 创建被拒绝后，任务编辑器仍显示且草稿保持不变，界面显示`无法新建对话，请重试。`，并且不添加任务。 |
| AC-11 | 取消待处理的新建 Session 提交后，编辑器会立即关闭；原请求之后返回时，既不添加任务，也不改变当前可见 Session。 |
| AC-12 | 进行中任务关联的 Session 含一个已完成、一个进行中和一个待处理 Todo 时，显示 `1/3` 和进行中 Todo 文本；关联同一 Session 的就绪任务不包含 progressbar。 |

## 已确认的方案细节

所选方案同时提供自由缩放和窗口／全屏两状态控件。窗口几何信息只是单次打开期间的临时展示状态。桌面窗口模式是默认值；响应式小屏模式等效于全屏。原型对比紧凑、可缩放和最大化三种展示，其中可缩放展示是正式实现候选方案。

创建操作集中到标题栏菜单中，并且只显示一个当前编辑器。新建任务关联会显式提供新建对话操作、不关联操作和已有 Session。新建对话路径复用当前 Workspace 的 Session 运行时与对话输入区，在跳转前把任务文本保留为尚未发送的草稿。

任务进度复用关联 Session 的现有 Todo 投影，并且只在 Todo 数据非空的进行中任务上显示，因此多个调度任务共用一个 Session 时，不会在非活动卡片上重复显示活动进度。
