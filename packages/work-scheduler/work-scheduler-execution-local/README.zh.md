# @deepseek-ai/dsh-work-scheduler-execution-local

[English](README.md) | 中文

[调度执行服务](../work-scheduler-execution/README.md)的原生提供者，依赖调度存储、Workspace 注册表、Agent 工厂、Session 持久化、模型选择、预设和托管子进程服务。[Web 调度 bundle](../../bundle/work-scheduler/README.md)提供组合配置。

## 准入与生命周期

执行先校验任务、验收条件、模型、预设及所选 Git 版本，再提交排队轮次。轮次保留已解析的基础提交、不可变任务输入、命令标识及专属 Session ID。重复提交复用轮次；旧修订号被拒绝。调度器遵守全局容量及线程前序顺序。审查通过释放前序任务；显式异步让出移除其线程占位并保留返回位置。

每次执行在 `worktreeRoot` 下创建 detached worktree，并在专属 Session 中挂载所选原生预设。规范化的 worktree 目录单独注册为 Workspace；原调度文档拥有执行轮次。用户分支引用和原目录未提交文件不变。成功由原生输入与正常结束的 turn 事件确定，单独的 idle 通知不能证明成功。

取消中止准备或模型工作，发布停止中，并在原生 Session 释放后记录已停止。Host 释放先停止准入并等待拥有的执行。激活时排队记录可以继续调度；其他失去所有者的待完成记录标记为中断，重试前需要人工检查。失败或停止后的重试使用新选择的基础版本；返工使用上一轮保留的产物提交。

## 审查证据

正常完成先释放 Agent，再收集证据。Git 快照包含受跟踪的修改与未被忽略的新文件；`refs/dsh/scheduler/<attempt-id>` 保留内部提交用于返工及检查。证据绑定输入提交、输出树、完整 Session 日志摘要哈希及终止序号。展示数据包含支持二进制的有界差异、助手摘要及实际工具参数和结果。工具错误、原生 bash 非零退出或中断结果保留为失败；任意工具文本不会被归类为通过检查。

审查拒绝仍活跃的 Session、变化的日志、不匹配的证据哈希及变化的 worktree。刷新固定新的文件证据，并保留重试标识。工具记录包含失败时，通过审查需要接受原因。返工需要反馈，并从固定输出创建新轮次。人工决策持久化保存，不合并或推送用户分支。

## 配置与产物

`worktreeRoot` 必须是绝对目录。`maxConcurrentRuns`、`maxQueuedRuns` 和 `dispatchIntervalMs` 控制准入与调度；`gitTimeoutMs`、`gitGraceMs` 和 `maxEvidenceBytes` 限制托管 Git 操作及展示证据。配置校验提供默认值，参见[配置目录](../../../docs/config-catalog.md)。

产物和内部引用永久保留。清理是独立显式操作：检查对应轮次后使用 Git worktree 与引用管理命令。插件不会递归删除用户仓库。worktree 隔离代码改动；工具权限与沙箱策略由所选预设决定。

## 模型体验

### 专属任务输入

#### 模型看到什么

原生用户消息包含冻结的任务描述、验收条目、可选返工反馈，以及在隔离目录完成工作、运行相关检查、总结实际结果与未完成项、不推送或合并的指令。精确文本由 `executionPrompt` 管理。工具 schema 和其他提示内容由预设管理。完整输入、工具调用及响应保存在专属 Session 日志。

#### Token 影响

每轮一个任务输入，长度随描述、验收条件和反馈增长。返工创建新 Session，不重放上一轮完整对话。

#### KV Cache 影响

任务输入位于预设前缀之后。每轮使用独立 Session，提供者不修改现有可复用对话前缀。

## 已知限制与延期工作

- 需要 Git 和已有提交；快照不包含原目录未提交改动与被忽略文件。
- worktree、Session、Workspace 注册及内部引用需要显式保留管理。不自动合并、推送、创建 PR 或垃圾回收。
- 重启恢复保守地中断无法确认的非排队轮次，不接管外部进程或自动重发模型输入。
- 展示限制可能需要用户查看完整 Session 日志和保留的 Git 产物。通过审查指向固定快照，不涵盖目录后续修改。
