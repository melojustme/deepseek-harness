# @deepseek-ai/dsh-client-ui-work-scheduler

[English](README.md) | 中文

dsh Web 的线程式个人工作调度插件。它通过现有 slot 系统在侧栏底部注册入口，并在全屏浮层中呈现调度板。每条线程按顺序推进任务：同步阻塞会暂停该线程后方任务，异步阻塞会把任务移入独立等待列表，并保留唤醒后的返回位置。

## 持久化与迁移

插件在浏览器 localStorage 的 `dsh.work-scheduler.v1` 键下保存一份带版本的 JSON 文档。存储内容不是有效 JSON 时从空调度板开始。导入时会规范化任务状态和位置，移除未知或重复引用，并把其余未放置任务分配到对应的待分配、异步阻塞或归档列表。导出会下载规范化后的 JSON 文档。

该文档属于当前浏览器配置文件，不是 Session 数据，不跟随 dsh Workspace，也不通过 Host 同步。

## 组合

侧栏入口和全屏浮层共享同一个插件自有 store。移除客户端条目会同时撤销两个 slot 贡献。随附 Web bundle 在声明这些 slot 的侧栏和布局所有者之后加载本插件。

## 模型体验

### 浏览器本地调度状态

#### 模型看到什么

模型看不到存储在 `dsh.work-scheduler.v1` 下的调度状态。本插件不增加提示词、工具 schema、请求字段、Session 事件或模型可见结果。

#### Token 影响

本插件不会向模型请求添加 token。

#### KV Cache 影响

本插件不改变模型请求，因此不会使原本可复用的前缀失效。

## 已知限制与延期工作

- 状态仅保存在一个浏览器配置文件中，不会跨设备或 dsh Web 来源同步。
- 任务不会启动、停止或监控 dsh Session、工作流、后台作业或子 agent。
- 导入会在规范化后替换当前文档；插件不会合并两份调度文档。
